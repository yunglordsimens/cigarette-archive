# Cigarette Archive

A personal digital archive and interactive sculpture made from a collection of cigarette packs. The project explores how objects hold memories, and what it means to let a collection go.

## About the project

For years, everyday objects acted as memory anchors. A pack or receipt could bring back a vivid moment. Travel and the experience of having to leave belongings behind changed that relationship: life matters more than possessions, and saving everything for later can keep us from living now.

The physical collection became a sculpture. This archive gives it a digital form: part inventory, part monument, and part act of letting go.

## Explore

The site includes:

- **Archive List:** a visual inventory of the collection.
- **Cross Visualization:** an interactive 3D CSS sculpture with pan, zoom, and angle controls.
- **About Project:** the project story and manifesto.

[Open the Cigarette Archive](https://yunglordsimens.github.io/cigarette-archive/)

## Run locally

```bash
git clone https://github.com/yunglordsimens/cigarette-archive.git
cd cigarette-archive
npm install
npm run dev
```

To create a production build:

```bash
npm run build
```

The project uses React and Vite. The 3D sculpture is built with CSS transforms.
